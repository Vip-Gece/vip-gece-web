# VIP GECE Yönetim Mobil

Bu klasor VIP GECE gizli admin panelini Android APK ve iOS IPA olarak paketlemek icin Capacitor kabidir.

- Baslangic ekrani: `https://vip-gece.site/vg-panel-91x`
- Gorsel ciktilari paneldeki `Indir` dugmesiyle standart indirme akisina verilir.
- Android derleme hedefi: `android/app/build/outputs/apk/debug/app-debug.apk`
- iOS proje hedefi: `ios/App/App.xcworkspace`

APK derlemesi yavru-gpu uzerinde yapilabilir. iOS projesi Mac uzerinde simulator acmadan Xcode ile derlenir; cihaz IPA kurulumu icin gecerli iOS signing/provision gerekir.
