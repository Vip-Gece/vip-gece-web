### 06.2 Yeni VPS Kurulum Adımları

```bash
# 1. Temel sistem güncellemesi
sudo apt update && sudo apt upgrade -y
sudo apt install -y ca-certificates curl ufw nginx certbot python3-certbot-nginx

# 2. Node.js kurulumu
# Temiz kurulumda internetteki scriptler doğrudan shell'e pipe edilmeyecek.
# Node.js paketi doğrulanmış OS deposundan veya önceden doğrulanmış offline paketten kurulacak.
sudo apt install -y nodejs npm
node --version
npm --version

# 3. PM2 kurulumu
sudo npm install -g pm2

# 4. Firewall yapılandırması
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable

# 5. SSH hardening
sudo sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart sshd

# 6. Kullanıcı oluştur
sudo useradd -m -s /bin/bash ubuntu
sudo usermod -aG sudo ubuntu
# SSH anahtarı ekle
sudo mkdir -p /home/ubuntu/.ssh
sudo chmod 700 /home/ubuntu/.ssh
# (SSH public key'i kopyala)
sudo chown -R ubuntu:ubuntu /home/ubuntu/.ssh
sudo chmod 600 /home/ubuntu/.ssh/authorized_keys

# 7. Deploy dizinleri oluştur
sudo mkdir -p /var/www/vip-gece-site/releases
sudo mkdir -p /var/lib/vip-gece
sudo mkdir -p /opt/vip-gece/domain-gateway
sudo chown -R ubuntu:ubuntu /var/www/vip-gece-site
sudo chown -R ubuntu:ubuntu /var/lib/vip-gece
sudo chown -R ubuntu:ubuntu /opt/vip-gece
```

### 06.3 Uygulama Deploy

```bash
# 1. Temiz kaynak paketini yerleştir
cd /var/www/vip-gece-site/releases
mkdir -p $(date +%Y%m%dT%H%M%SZ)-clean-source
# Doğrulanmış temiz runtime paketi bu dizine açılacak

# 2. Release dizini oluştur
RELEASE_DIR=$(ls -d */ | sort | tail -1)
cd "$RELEASE_DIR"
mv runtime . 2>/dev/null || true

# 3. Production .env oluştur (YENİ secret'larla)
sudo nano /var/www/vip-gece-site/current/.env
# (aşağıdaki .env template'ini kullan)
sudo chmod 600 /var/www/vip-gece-site/current/.env

# 4. Dependencies kur
npm ci --omit=dev

# 5. Symlink'leri oluştur
cd /var/www/vip-gece-site
ln -sfn releases/$RELEASE_DIR current
ln -sfn releases/$RELEASE_DIR rollback

# 6. PM2 ile başlat
cd /var/www/vip-gece-site/current
pm2 start server.modular.js --name vip-gece-site
pm2 save
pm2 startup
```

### 07.3 Rollback Planı

**Senaryo A — DNS cutover öncesi sorun:**
```bash
# Yeni VPS'te sorun varsa, DNS'i değiştirme
# Eski VPS hâlâ çalışıyor (erişilemese bile DNS hâlâ eski IP'ye işaret ediyor)
# Sorunu çöz, tekrar dene
```

**Senaryo B — DNS cutover sonrası sorun:**
```bash
# Cloudflare DNS'i eski VPS IP'sine geri al
# vip-gece.site A → ESKI_ORIGIN_IP_KALDIRILDI (proxy ON)
# vip-gece.site AAAA → ESKI_ORIGIN_IPV6_KALDIRILDI (proxy ON)
# vip-gece.online A → ESKI_ORIGIN_IP_KALDIRILDI (proxy OFF)

# ANCAK: Eski VPS erişilemez — bu rollback çalışmaz!
```
