# VIP GECE Design Tool Stack - 2026-06-26

Kaynak hedef: repo icindeki completion audit ve dis proof kanitlari.

Bu not eski listedeki hazir tasarim/tool incelemesi, ek plugin fikirleri ve secilen personal design suite kararini kalici hale getirir.

## Hazir Tasarim ve Uretim Araclari

- Figma: frame, component library, design system ve code-to-design sync icin.
- Canva: hizli sosyal gorsel, sunum ve marka asset taslaklari icin.
- Base44: dogal dille web app / website prototipi icin.
- Lovable: full-stack siteyi dis editorde hizli buyutme ve deneme icin.
- Product Design: fikirden yon, prototype akisi ve UI audit icin.
- Vercel: modern web deploy ve preview paylasimi icin.
- Netlify: alternatif hosting/deploy, form ve edge workflowlari icin.
- HyperFrames: motion-heavy hero ve animasyonlu web bolumleri icin.
- Shutterstock: stok gorsel ve medya arama hattı icin.
- Medya polish araclari: yalniz marka varliklarini duzenleme ve insan onayli tasarim
  hazirligi icin; otomatik profil veya ilan uretimi kapsam disidir.
